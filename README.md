Uses the (Lumina)[https://github.com/sohamch08/lumina] theme.

Change the following files to update:
- main.tex:  Holds the actual content.
- config.tex: Configure the title, instructor, semester, author, and color scheme
- title.tex: Change the layout of the title page

In the main content, use the following commands:
- `\chapter`: New chapter
- `\section`: New section
- `\dfn`: Insert definition
- `\nt`: Insert a note
- `\thm`: Insert a theorem
- `\pf`: Insert proof
- `\ex`: Insert example
- I also have specified a new command, `\assignment` that inserts text that says "Connection to your assignment.".
